# 网页标注 · Highlight & Annotate

<img src="icons/icon-128.png" width="96" alt="网页标注">

在网页上高亮选中的文字，写备注、加标签。标注按网站整理，可搜索，可导出 Markdown。

[English](README.md)

## 功能

- 按住修饰键选中文字即完成高亮，六种颜色
- 右键菜单自选颜色
- 每条标注可写备注、加标签
- 侧边栏列出当前页标注，点击定位
- 管理页按网站、页面分组，支持搜索、标签与颜色筛选、批量删除
- 可新建目录归整网站，新标注按默认目录自动归档
- 导出 Markdown，可选包含备注、标签、颜色、日期
- 全量 JSON 备份与恢复
- 界面中文 / English 可切换

## 环境要求

Chrome 114 或更高版本。无构建步骤，无第三方依赖。

## 安装

1. 在 [Releases](../../releases) 下载 `web-annotation-0.1.0.zip` 并解压
2. 打开 `chrome://extensions`，开启右上角「开发者模式」
3. 点「加载已解压的扩展程序」，选择解压后的目录

从源码安装：克隆仓库后，在第 3 步选择含 `manifest.json` 的那一层目录。

## 使用

| 操作 | 效果 |
|---|---|
| `Ctrl` + 选中文字（macOS 为 `Cmd`） | 用默认颜色高亮 |
| 右键 → 标注所选文字 | 自选颜色 |
| 点击已有高亮 | 改颜色、写备注、加标签、删除 |
| 点击工具栏图标 | 打开侧边栏 |

修饰键、触发方式、默认颜色在设置页修改；也可以关掉自动高亮，只用右键菜单。

## 数据

标注存在扩展的 IndexedDB 里，不受浏览器「清除浏览数据」影响。卸载扩展或更换浏览器配置目录会丢失，建议在设置页定期导出 JSON 备份。
