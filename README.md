# 网页标注

在网页上高亮选中的文字，像读 PDF 一样做标注。标注按来源网站整理，可搜索、可筛选、可导出 Markdown。

Chrome 扩展，Manifest V3，零构建、零依赖 —— 加载已解压的扩展即可运行。

---

## 功能

- **高亮文字**：按住修饰键选中一段文字即完成标注，无中间步骤
- **多颜色**：六色调色板，右键菜单可选色
- **备注与标签**：每条标注可写备注、加标签
- **侧边栏**：浏览网页时查看当前页标注，按文档内位置排序，点击定位
- **管理页**：全部标注按网站/页面分组，可把网站归入自定义目录；支持搜索、按标签/颜色筛选、批量删除，标签与颜色筛选在当前目录内生效
- **默认目录**：在侧边栏选一个目录，之后新标注所在的网站会整体归档到该目录；选「顶层」关闭自动归档。目录被删除后配置自动失效，网站回到顶层
- **中英双语界面**：设置页可切换中文 / English，仅影响扩展自身，不影响网页
- **导出 Markdown**：按网站或页面分组，可选是否包含备注、标签、日期、颜色
- **备份与恢复**：全量 JSON 导出导入

## 安装

### 从 Releases 安装

1. 在 [Releases](../../releases) 下载 `web-annotation-<版本>.zip` 并解压
2. 打开 `chrome://extensions`，打开右上角「开发者模式」
3. 点「加载已解压的扩展程序」，选择解压后的 `web-annotation` 目录

### 从源码加载

1. 克隆仓库，或下载源码压缩包并解压
2. 打开 `chrome://extensions`，打开右上角「开发者模式」
3. 点「加载已解压的扩展程序」，选择含 `manifest.json` 的那一层目录

无需构建。需要 Chrome 114 或更高版本。

## 使用

| 操作 | 效果 |
|---|---|
| `Ctrl` + 选中文字（macOS 用 `Cmd`） | 用默认颜色高亮 |
| 右键 → 标注所选文字 | 自选颜色 |
| 点击已有高亮 | 打开编辑浮层：改颜色、写备注、加标签、删除 |
| 点击工具栏图标 | 打开侧边栏 |

创建后左下角出现带「撤销」的提示条。按 `Esc` 关闭浮层。

修饰键、触发方式、默认颜色在设置页配置。

设置页有两种自动触发方式：

- **选中即高亮**：按住修饰键（默认 `Ctrl`，macOS 为 `Cmd`）选中文字，立即用默认颜色高亮
- **选中后弹工具条**：普通选中文字即可，选区旁弹出颜色工具条，点颜色才保存，不需要修饰键
- **两个都不选**：不自动触发，只能用右键菜单

修饰键只在「选中即高亮」时需要，其他状态下该项在设置页里禁用。

管理页左侧只有「全部网站」一个顶层目录：新网站默认直接挂在它下面，可新建目录并把网站移入。删除目录会连带删除该目录下的全部标注，确认框会先写明数量。

侧边栏顶部的「默认目录」是全局设置，不按网站区分：选定后一直生效，之后在任何网站上新加标注，都会把这个网站整体归档到该目录；选「顶层」表示不自动归档。归档粒度是网站，所以同一个网站不会分散在两个目录里。目录被删除后，默认目录自动失效，网站回到顶层。

从侧边栏点「管理」会在新标签页打开管理页。

## 数据

标注存在浏览器分配给扩展的独立存储里（IndexedDB）。

- **不受「清除浏览数据」影响** —— 浏览器把扩展存储排除在外
- 关浏览器、重启电脑、异常断电都不丢失
- 申请了 `unlimitedStorage` 权限，免除配额限制与磁盘紧张时的回收
- 物理位置在 Chrome 用户配置目录内，扩展无法更改，Chrome 也不支持移动该目录

会丢失数据的情况：卸载扩展、更换 Chrome 用户配置、更换浏览器。

因此建议定期用设置页的**导出备份**保存一份 JSON，该文件也可用于跨设备迁移。

## 已知限制

- **iframe 内的内容无法标注** —— 仅支持顶层页面。跨 frame 锚定需记录 frame 链路，复杂度与出错面显著上升。
- **封闭式 Shadow DOM 内的文字无法选中** —— 拿不到其引用。
- **高亮样式限于背景色、文字色、下划线** —— 浏览器的 `::highlight()` 只接受这几类属性，
  不支持圆角、内边距与边框。
- **部分页面无法注入** —— `chrome://` 页面、扩展商店、Chrome 内置 PDF 阅读器。
  本地文件需在扩展详情页手动开启「允许访问文件网址」。
- **不做跨设备同步** —— 浏览器自带的同步存储配额不足以承载标注数据，跨设备请用导出备份与导入。
