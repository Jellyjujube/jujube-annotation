数据存在哪里 —

存在浏览器分配给我们这个扩展的独立存储里。它不会被「清除浏览数据」清掉，关浏览器、重启电脑、甚至断电崩溃都不影响。物理位置在 Chrome 的用户配置目录内，这个位置扩展改不了，Chrome 也不支持移动它。

查看实际路径

如果想自己确认或备份整个目录，可以到下面这个位置找。路径中的 是扩展的固定 ID。

什么情况下会丢
  • 卸载扩展 浏览器会连带删除该扩展的全部存储。卸载前请先导出备份。
  • 换 Chrome 用户配置，或换浏览器 数据跟着配置走，Edge / Brave 各存各的。
  • 清空扩展数据（需要在扩展详情页单独操作）。

所以建议偶尔导出一份备份文件，扔进网盘或 Git 都行 —— 那同时也等于实现了跨设备迁移。
